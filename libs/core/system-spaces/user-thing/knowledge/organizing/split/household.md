# Household admin — split by standing home domain

Splits by each standing DOMAIN of running the home the user would seek advice on — home and contents
insurance, each utility/energy supply, the mortgage or tenancy, and each major appliance or system
(the boiler/heating, etc.). Each is a specialist advising on how that part works.

The records are DATA: bills, amounts, due dates, payments, meter readings, policy and account
numbers, renewal dates. Never make a "bills", "payments", or "renewals" specialist — those are rows.
