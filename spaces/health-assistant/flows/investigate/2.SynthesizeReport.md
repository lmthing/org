# Phase 2 — Synthesize and Submit

Compose the research report from the gathered excerpts and submit.

```ts
// ── submit ────────────────────────────────────────────────────────
__flow.start("submit");

const topic = userQuestion;
const summary = "TL;DR based on gathered evidence (2-4 sentences).";
const findings = excerpts.map((e, i) => ({
  claim: `Extracted claim from source ${i + 1}`,
  evidence: e,
  sourceId: i + 1,
}));
const sources = searchResults.flatMap((r, i) => [{ id: i + 1, url: `source-url-${i + 1}` }]);

submitResearch({
  topic,
  summary,
  findings,
  sources,
  disclaimer: "This is for informational purposes only. Consult a healthcare professional for medical decisions.",
});
```
