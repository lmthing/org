# Phase 3 — Compose and submit

Build the final briefing markdown and submit it.

```ts
// ── compose ──────────────────────────────────────────────────────────────
__flow.start("compose");

const cats = /* from categorise */;
const feat = /* from fetch_details */;
const now = new Date().toLocaleDateString("en-US", { weekday: "long", year: "numeric", month: "long", day: "numeric" });

let briefing = `# Morning Briefing — ${now}\n\n`;

// Lead story — the featured article from the biggest category
const lead = feat[0];
if (lead) {
  briefing += `## Lead Story\n\n**${lead.title}**\n*${lead.source} — ${lead.pubDate}*\n\n${lead.content.slice(0, 800)}\n[Read more](${lead.url})\n\n`;
}

// Per-category sections
for (const cat of cats) {
  if (cat.articles.length === 0) continue;
  briefing += `## ${cat.name.charAt(0).toUpperCase() + cat.name.slice(1)} (${cat.articles.length} stories)\n\n`;
  for (const art of cat.articles.slice(0, 5)) {
    briefing += `- **${art.title}** — [${new URL(art.link).hostname.replace(/^www\./, "")}](${art.link})\n`;
  }
  // Featured deep-dive for this category
  const featuredArt = feat.find(f => f.category === cat.name);
  if (featuredArt && featuredArt !== lead) {
    briefing += `\n  *Featured:* ${featuredArt.content.slice(0, 400)}\n\n`;
  }
  briefing += "\n";
}

briefing += `---\n*Generated from ${/* stats.total */0} articles across ${/* stats.feedsChecked */0} feeds.*\n`;
__flow.finish("compose", { briefing });

// ── submit ───────────────────────────────────────────────────────────────
__flow.start("submit");
submitBriefing(briefing);
__flow.finish("submit");
```

No `inspect()` — call `submitBriefing` directly. The session ends when the sink fires.
