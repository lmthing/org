# Phase 3 — Synthesize and submit

Build the investigation report with confidence-tagged claims.

```ts
// ── synthesize ───────────────────────────────────────────────────────────
__flow.start("synthesize");

const report = `# Investigation Report: ${/* original query */""}

## Executive Summary
<2-4 sentence overview of what was found>

## Key Findings

### Confirmed (multi-source)
${/* confirmed claims with [source-N] citations */}

### Likely
${/* claims with strong but not full corroboration */}

### Unverified (single source)
${/* claims from only one source */}

### Disputed
${/* claims where sources disagree */}

## Key Entities
${/* extracted entities grouped by type */}

## Source Analysis
${/* credibility and bias summary for each source used */}

## Sources
${/* numbered source list with URLs and credibility scores */}
`;
__flow.finish("synthesize", { report });

// ── submit ───────────────────────────────────────────────────────────────
__flow.start("submit");
submitInvestigation(report);
__flow.finish("submit");
```
