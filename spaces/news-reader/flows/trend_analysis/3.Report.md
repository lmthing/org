# Phase 3 — Synthesize and submit

Build the trend analysis report.

```ts
// ── synthesize ───────────────────────────────────────────────────────────
__flow.start("synthesize");
const topic = /* original topic */;
const windows = /* timeWindows */;
const entities = /* entityFrequency */;
const framing = /* outletFraming */;
const timeline = /* narrativeTimeline */;

const totalDay = windows.find(w => w.label === "past_24h")?.articleCount ?? 0;
const totalWeek = windows.find(w => w.label === "past_week")?.articleCount ?? 0;
const totalMonth = windows.find(w => w.label === "past_month")?.articleCount ?? 0;
const trend = totalDay > (totalWeek / 7) * 1.5 ? "rising" : totalDay < (totalWeek / 7) * 0.5 ? "declining" : "stable";

let report = `# Trend Analysis: ${topic}\n\n`;
report += `## Coverage Summary\n`;
report += `- Last 24h: ${totalDay} articles\n`;
report += `- Last 7 days: ${totalWeek} articles (avg ${Math.round(totalWeek / 7)}/day)\n`;
report += `- Last 30 days: ${totalMonth} articles\n`;
report += `- **Trend: ${trend.toUpperCase()}**\n\n`;

report += `## Key Entities\n\n| Entity | Type | Mentions |\n|--------|------|----------|\n`;
for (const e of entities.slice(0, 15)) {
  report += `| ${e.text} | ${e.type} | ${e.count} |\n`;
}

report += `\n## Outlet Framing\n\n| Outlet | Framing | Top Claim |\n|--------|---------|----------|\n`;
for (const f of framing) {
  report += `| ${f.source} | ${f.framing} | ${f.keyClaims[0]?.slice(0, 80) ?? "—"} |\n`;
}

if (timeline.length > 0) {
  report += `\n## Narrative Timeline\n\n`;
  for (const t of timeline) {
    report += `- **${t.date}**: ${t.event}\n`;
  }
}

report += `\n## Outlook\n\n`;
report += `Based on ${totalWeek} articles from the past week, `;
report += trend === "rising" ? "this topic is gaining momentum and likely to remain prominent." :
  trend === "declining" ? "coverage is waning — this topic may be losing mainstream attention." :
  "coverage remains steady — this is an ongoing story with sustained interest.";

__flow.finish("synthesize", { report });

// ── submit ───────────────────────────────────────────────────────────────
__flow.start("submit");
submitTrendReport(report);
__flow.finish("submit");
```
