# Phase 3 — Synthesize, verify, submit

```ts
// ── synthesize ──────────────────────────────────────────────────────────
__flow.start("synthesize");

// REQUIRED GUARD: check for empty evidence FIRST — never fabricate.
const hasClaims = Array.isArray(__claims) && __claims.length > 0;
const brief = !hasClaims
  // No evidence gathered (search failed or returned nothing): report honestly.
  ? `# ${/* restate the question */""}\n\n## TL;DR\nNo usable information was found. Web searches returned no accessible content for this query. Try a more specific search or check provider configuration.\n\n## Findings\n- No evidence was retrieved from any source.\n\n## Sources\n(none)`
  // Evidence present: synthesize from __claims.
  : `# <restated question>

## TL;DR
<2–4 sentences answering directly>

## Findings
- **<claim from __claims>** — [source-N]
- ...

## Disagreements / open questions
- ...

## Sources
[source-1] <Title> — <url>
`;
__flow.finish("synthesize", { brief });

// ── verify ──────────────────────────────────────────────────────────────
__flow.start("verify");
// Self-check: every [source-N] marker in `brief` must appear in the Sources
// section, and vice versa. The TL;DR must answer the original task.
// citationsOk = false if no real sources were cited.
const citationsOk = hasClaims && brief.includes("[source-");
__flow.finish("verify", { brief, citationsOk });

// ── submit ──────────────────────────────────────────────────────────────
__flow.start("submit");
submitBrief(brief);
__flow.finish("submit");
```

No `inspect()` in the final phase — call `submitBrief` directly. The session terminates as soon as the sink fires.

## Brief format requirements

- One markdown document, no code fences wrapping the whole thing.
- `[source-N]` markers on every claim in **Findings**.
- The `Sources` section enumerates `[source-N] <Title> — <url>` for every N referenced.
- Paraphrase by default; quote only short load-bearing phrases.
- Flag disagreements explicitly in their own section.
- If the gathered material doesn't answer, say so in the TL;DR with a suggested follow-up.
