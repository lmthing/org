# Brave Search

Built on Brave's own crawled index — independent of Google/Bing. Good general-purpose default, strong freshness filtering (`pd`/`pw`/`pm`/`py`).

**When to use**
- Default general-purpose web search
- Counterbalance to Google-derived providers (Serper, SerpAPI, CSE)
- Privacy-respecting queries
