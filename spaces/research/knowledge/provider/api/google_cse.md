# Google CSE

Official Google API. Requires both an API key (`GOOGLE_CSE_API_KEY`) and a Custom Search Engine ID (`GOOGLE_CSE_CX`). Free tier is 100 queries/day. Limited to 10 results per call.

Use this when you need *officially-sanctioned* Google results without ToS concerns about scraping.
