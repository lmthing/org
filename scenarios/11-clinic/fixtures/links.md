# Links Ruth keeps meaning to read

Provenance for the one research beat in this scenario. Nothing in the practice's own files carries
a rehabilitation protocol — the notes describe how the *practice* runs, never how a knee is
rehabilitated — so a question about the standard phases after an ACL reconstruction is a genuine
knowledge miss that has to be looked up and then kept, with its source, in the space that owns it.

Stable, canonical, fetchable reference pages (no login, no paywall, no scraping defences):

- Anterior cruciate ligament reconstruction — https://en.wikipedia.org/wiki/Anterior_cruciate_ligament_reconstruction
  Why: the phased post-operative rehabilitation timeline (immediate mobilisation, weeks 2–6,
  strengthening, return to running / return to sport criteria) that Ruth's course template should
  match. Referral REF-2026-0834 in `intake-email.md` is exactly this operation.
- Physical therapy — https://en.wikipedia.org/wiki/Physical_therapy
  Why: the background an advising agent needs about scope of practice and modalities before it
  offers an opinion on a treatment plan.
- Anterior cruciate ligament injury — https://en.wikipedia.org/wiki/Anterior_cruciate_ligament_injury
  Why: the injury side of the same story — graft choice (hamstring autograft, as in the referral)
  and what it implies for early loading.

None of these facts appears in `practice-notes.md`, `patients-export.csv`,
`appointments-export.csv`, `insurance-codes.csv` or `intake-email.md` — checked, so a search here is
a real miss and a *second* search for the same thing is a real failure.
