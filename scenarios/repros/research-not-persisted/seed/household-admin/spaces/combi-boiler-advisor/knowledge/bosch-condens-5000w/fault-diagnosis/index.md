Fault diagnosis for the Bosch Condens 5000 W (ZWB 37-2 A) gas combi boiler. This field covers the fault codes the boiler displays when something goes wrong, what each code means, and the likely causes and remedies. Every fault code and its description here is drawn directly from the manufacturer's service manual — the same document a qualified technician would consult on-site. Use this field to identify a fault by its display code and understand the repair path before calling a contractor.
