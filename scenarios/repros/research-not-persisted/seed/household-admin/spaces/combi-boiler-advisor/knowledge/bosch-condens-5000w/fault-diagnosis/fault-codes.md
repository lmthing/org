# Fault Codes

When the Bosch Condens 5000 W detects a problem, the Heatronic control module shows a code on the two-digit display and may sound a warning tone. The reset button may flash. The boiler can display the following fault codes (directly from the manufacturer's service manual):

- **A7** — DHW temperature sensor faulty (ZWB). Check sensor and lead for breaks/shorts.
- **A8** — BUS communication fault. Check controller connecting lead.
- **Ad** — Cylinder temperature sensor not detected.
- **b1** — Code plug not detected. Reseat or replace the boiler coding card.
- **b2–b6** — Internal data error. Restore Heatronic 3 to standard settings (service function 8.E).
- **C6** — Fan not running. Check fan lead, connector, and fan.
- **CC** — Outside temperature sensor not detected (weather-compensated controller).
- **d3** — External temperature limiter faulty or tripped.
- **d5** — External flow temperature sensor defective.
- **E2** — CH flow temperature sensor faulty. Check sensor and lead.
- **E9** — Heat exchanger temperature limiter or flue gas temperature limiter has tripped. Check system pressure, pump, heat exchanger, and vent the appliance.
- **EA** — Flame not detected. Check gas supply, electrodes, flue system, gas-air ratio, condensate trap, heat exchanger, and gas valve.
- **F0** — Internal fault. Press reset for 3 seconds; if it persists, check plug-in contacts and ignition leads.
- **F1** — Internal data error. Restore to standard settings.
- **F7** — Flame detected while appliance is off. Check electrodes, flue system, and PCB for moisture.
- **FA** — Flame detected after gas shut-off. Check gas valve, condensate trap, electrodes, and flue system.
- **Fd** — Reset pressed in error. Press reset again.

In all cases, if pressing reset does not clear the fault, switch the appliance off and on at the main switch. If the fault persists, call an authorised contractor.
