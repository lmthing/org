# dimensions-install

Physical dimensions and minimum installation clearances from the Bosch Condens 5000 W manual (6 720 644 143, 2016/04), section 3.7.

## Casing dimensions
- Width × Height × Depth: **440 × 760 × 360 mm**

## Minimum clearances (see manual Fig. 2, page 9)
- Sides: minimum **5 mm**
- Above elbow: additional **30 mm** above the flue elbow
- Front clearance for service: **600 mm** (or **20 mm** to a reversible door when service access is not needed from the front)
- Using 100 mm flue kit: overall height reference **1112 mm**; using 120 mm flue kit: **1152 mm**

## Weight (excluding packaging)
- ZSB 30-2 A: **46.5 kg**
- ZWB 37-2 A: **48.5 kg**
- The ZWB 30-2 A combi is expected to weigh comparably to the ZWB 37-2 A (approx. 48 kg).

## Installation notes (manual section 3.1)
- The appliance is intended for **indoor use only**, in a sealed unvented central heating system.
- It must not be used as a pool heater.
- Commercial and industrial use for process heat is not permitted.
- Installation site: must be built from or lined with non-combustible material if enclosed in a cupboard or compartment after installation.
- The appliance is room-sealed — no ventilation openings are required in the compartment if the stated clearances are maintained.
- Permissible ambient temperature: **0 – 50 °C**
