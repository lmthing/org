# non-display-faults-173

Section 17.3 of the manual (6 720 644 143, 2016/04) lists faults that produce symptoms but generate NO two-character display code. These require physical inspection and diagnostic reasoning:

- **Combustion noise too loud / rumbling** — check coding card, gas type, gas supply pressure, flue gas system, and gas/air ratio; replace gas valve if needed.
- **Flow noises** — set pump stages or pump characteristic maps correctly and match to maximum output; set pump mode correctly.
- **Heat-up takes too long** — set pump stages/characteristic maps correctly and match to maximum output; set pump mode correctly.
- **Flue gas readings incorrect / CO levels too high** — check gas type, gas supply pressure, flue gas system, and gas/air ratio; replace gas valve if needed.
- **Ignition too harsh or poor** — check gas type, gas supply pressure, power supply, electrodes and leads, flue gas system, gas/air ratio, burner, and external gas flow limiter (natural gas); replace gas valve or burner if required.
- **Set flow temperature exceeded** (e.g. FW-100 controller) — switch OFF automatic cycle block (set to 0), then set the required cycle block (e.g. standard 3 minutes).
- **Condensate in air box** — insert diaphragm in the mixing facility as per installation instructions; replace if required.
- **DHW temperature not reached (ZWB)** — check coding card is correctly plugged in; check turbine and replace if required.
- **Heatronic flashing** (all keys, display segments, burner indicator flashing) — replace fuse Si 3 (24 V).
- **Set room temperature not reached** — de-aerate the hydronic system, check thermostatic radiator valves, check controller demand, and complete air purge (service function 2.C).

These faults often stem from installation or commissioning issues rather than component failure, so always check system setup before replacing parts.
