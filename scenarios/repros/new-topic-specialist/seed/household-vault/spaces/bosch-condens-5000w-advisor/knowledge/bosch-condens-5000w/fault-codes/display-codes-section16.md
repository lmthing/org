# display-codes-section16

Section 16 of the Bosch Condens 5000 W service manual (6 720 644 143, 2016/04) covers the fascia displays shown during normal operation and status indication — not fault codes. These include:

- **Two-digit numbers** — decimal values such as flow temperature (00–99).
- **U followed by 0–9** — decimal values 100–109 (e.g. U0 = 100).
- **Three-digit values** — shown as a single digit alternating with the last two digits (e.g. 1…69…69 for 169).
- **Two dashes followed by two number pairs** — boiler coding card number, displayed in three stages (e.g. -- ..10..04).
- **Two letters followed by two number pairs** — software version number, displayed in three stages.
- **Special displays** include: rE (reset acknowledge), alternating flow temperature with = (set maximum rated output active), alternating flow temperature with || (minimum rated output active), alternating flow temperature with P (trap-filling programme active), alternating flow temperature with S (service interval elapsed), alternating flow temperature with H (heating circuit pump blocked), and alternating flow temperature with A (temperature gradient limiter enabled — heating suspended for two minutes).

These displays help identify the appliance's current operating mode and status before diagnosing a fault.
