Fault-code reference for the Bosch Condens 5000 W (ZWB 37-2 A / ZSB 30-2 A), drawn from the manufacturer service manual (6 720 644 143, 2016/04). The fault system splits into three aspects: (1) normal operating and status displays shown on the fascia during routine use (Section 16), (2) faults that the Heatronic module detects and shows as a two-character code on the display — these are the triggered safety or sensor faults with concrete remedies (Section 17.2, codes A7 through Fd), and (3) symptoms that are NOT shown as a display code but manifest as noise, performance issues, or incorrect readings — requiring diagnostic deduction by the engineer (Section 17.3). Use the right aspect depending on whether you see a code on the screen, see a non-code display, or hear/feel a symptom with no code at all.
