# Pulmonology

## Key Terms and Abbreviations

| Term | Abbreviation | Meaning |
|------|-------------|---------|
| Chronic Obstructive Pulmonary Disease | COPD | Emphysema + chronic bronchitis |
| Forced Expiratory Volume (1 sec) | FEV1 | Airflow obstruction measure |
| Forced Vital Capacity | FVC | Total exhaled volume |
| FEV1/FVC Ratio | FEV1/FVC | < 0.7 = obstruction |
| Diffusing Capacity | DLCO | Gas transfer efficiency |
| Acute Respiratory Distress Syndrome | ARDS | Non-cardiogenic pulmonary edema |
| Pulmonary Embolism | PE | Lung clot |
| Obstructive Sleep Apnea | OSA | Airway collapse during sleep |
| Continuous Positive Airway Pressure | CPAP | OSA treatment |
| Non-Invasive Ventilation | NIV / BiPAP | Mask ventilation support |
| End-Tidal CO2 | EtCO2 | Capnography monitoring |
| Partial Pressure O2 / CO2 | PaO2 / PaCO2 | Arterial blood gas values |
| Alveolar-arterial Gradient | A-a gradient | Gas exchange efficiency |
| Bronchoalveolar Lavage | BAL | Airway washing for diagnosis |
| Exacerbation | -- | Acute worsening of chronic lung disease |

## Common Tests and Procedures

- **Spirometry (with bronchodilator response)** -- obstructive vs. restrictive pattern, severity grading
- **Complete PFTs (spirometry + lung volumes + DLCO)** -- comprehensive lung function
- **Arterial Blood Gas (ABG)** -- acid-base, oxygenation, ventilation assessment
- **Chest X-Ray** -- initial imaging for most pulmonary complaints
- **High-Resolution CT Chest (HRCT)** -- interstitial lung disease, bronchiectasis
- **CT Pulmonary Angiogram (CTPA)** -- pulmonary embolism diagnosis
- **Ventilation-Perfusion (V/Q) Scan** -- PE diagnosis when CTPA contraindicated
- **Bronchoscopy (flexible)** -- airway visualization, biopsy, BAL
- **Polysomnography (PSG)** -- sleep study for OSA, nocturnal hypoventilation
- **Six-Minute Walk Test (6MWT)** -- functional exercise capacity, oxygen desaturation
- **Pleural Thoracentesis** -- pleural effusion sampling

## Relevant Lab Markers and Reference Ranges

| Marker | Reference Range | Unit | Notes |
|--------|----------------|------|-------|
| PaO2 | 80 -- 100 (decreases with age) | mmHg | 60 = threshold for supplemental O2 |
| PaCO2 | 35 -- 45 | mmHg | > 45 = hypoventilation |
| pH (arterial) | 7.35 -- 7.45 | -- | |
| HCO3 (arterial) | 22 -- 26 | mEq/L | |
| A-a gradient | Age/4 + 4 (approximate) | mmHg | Elevated = V/Q mismatch or shunt |
| SpO2 | 95 -- 100% | % | < 88% = supplemental O2 indication |
| FEV1 | >= 80% predicted | % predicted | GOLD 1: >= 80, 2: 50--79, 3: 30--49, 4: < 30 |
| FEV1/FVC | >= 0.7 | ratio | < 0.7 = obstruction |
| DLCO | >= 80% predicted | % predicted | Low = emphysema, ILD, pulmonary HTN |
| TLC | 80 -- 120% predicted | % predicted | < 80 = restriction, > 120 = hyperinflation |
| D-dimer | < 500 | ng/mL FEU | Low pretest probability only |
| BNP | < 100 | pg/mL | Distinguish cardiac vs. pulmonary dyspnea |
| Procalcitonin | < 0.25 | ng/mL | Bacterial infection marker, guide antibiotics |
| Sputum Culture | No pathogenic organisms | -- | Quantitative > 10^5 CFU significant |

## Red-Flag Symptoms

- **Sudden-onset dyspnea + pleuritic chest pain + hemoptysis** -- PE (Wells score, CTPA)
- **Acute severe dyspnea + SpO2 < 88% despite supplemental O2** -- impending respiratory failure (ABG, NIV/intubation)
- **Massive hemoptysis** (> 100 mL/24 hr) -- airway protection first, then bronchoscopy
- **Tension pneumothorax** -- tracheal deviation, absent breath sounds, hypotension (needle decompression before imaging)
- **ARDS** -- bilateral infiltrates + PaO2/FiO2 < 300 + non-cardiogenic (ICU admission, low-tidal-volume ventilation)
- **COPD exacerbation with rising PaCO2** -- NIV (BiPAP) first line, intubate if no improvement
- **Sleep apnea with daytime hypercapnia** -- overlap syndrome (COPD + OSA), requires BiPAP not CPAP
- **New large pleural effusion with fever** -- empyema until proven (thoracentesis with culture)
- **Progressive dyspnea + bilateral crackles + DLCO decline** -- interstitial lung disease (HRCT, consider biopsy)
- **Status asthmaticus** -- no response to continuous albuterol + ipratropium + steroids (ICU, consider Mg, epinephrine)
