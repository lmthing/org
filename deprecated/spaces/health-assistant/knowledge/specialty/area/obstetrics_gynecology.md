# Obstetrics & Gynecology

| Term | Abbreviation | Meaning |
|------|-------------|---------|
| Last Menstrual Period | LMP | Dating reference for pregnancy |
| Estimated Date of Delivery | EDD | Due date (280 days from LMP) |
| Gestational Age | GA | Weeks + days of pregnancy |
| In Vitro Fertilization | IVF | Assisted reproductive technology |
| Preeclampsia | -- | Hypertension + proteinuria after 20 weeks |
| Eclampsia | -- | Preeclampsia + seizures |
| HELLP Syndrome | -- | Hemolysis, Elevated Liver enzymes, Low Platelets |
| Placenta Previa | -- | Placenta covering cervical os |
| Placental Abruption | -- | Premature placental separation |
| Gravida / Para | G/P | Number of pregnancies / births |
| Gestational Diabetes Mellitus | GDM | Diabetes diagnosed during pregnancy |

| Human Chorionic Gonadotropin | hCG | Pregnancy hormone marker |
| Fetal Heart Rate | FHR | Fetal monitoring baseline 110--160 bpm |

## Common Tests and Procedures

- **Urine/Beta-hCG** -- pregnancy confirmation
- **Quantitative Serum hCG** -- viability, ectopic surveillance, molar pregnancy
- **Transvaginal Ultrasound** -- early pregnancy viability, ectopic, dating
- **Obstetric Ultrasound (anatomy scan at 18--22 wk)** -- fetal anatomy, growth, placenta, amniotic fluid
- **First Trimester Screen (NT + PAPP-A + free beta-hCG)** -- aneuploidy screening
- **Cell-Free DNA (cfDNA / NIPT)** -- non-invasive prenatal testing for trisomies
- **Glucose Challenge Test / OGTT (24--28 wk)** -- gestational diabetes screening
- **Group B Strep Culture (35--37 wk)** -- intrapartum antibiotic prophylaxis decision
- **Cervical Cytology (Pap Smear)** -- cervical cancer screening (age 21--65)
- **HPV Testing** -- cervical cancer screening co-testing
- **Colposcopy with Biopsy** -- abnormal Pap follow-up
- **Bone Density (DEXA)** -- post-menopausal osteoporosis screening

## Relevant Lab Markers and Reference Ranges

| Marker | Reference Range | Unit | Notes |
|--------|----------------|------|-------|
| Beta-hCG (non-pregnant) | < 5 | mIU/mL | > 25 = pregnancy |
| Beta-hCG (gestational sac visible on US) | > 1,500--2,000 (transvaginal) | mIU/mL | Discriminatory level |
| Progesterone (early pregnancy) | > 10--20 suggests viable | ng/mL | < 5 suggests non-viable/ectopic |
| Hemoglobin (pregnancy) | > 11.0 (1st/3rd tri), > 10.5 (2nd tri) | g/dL | Physiologic hemodilution |
| Platelets (pregnancy) | 150 -- 400 | x10^3/uL | < 100 in HELLP |
| BP (pregnancy) | < 120/80 baseline | mmHg | >= 140/90 after 20 wk = preeclampsia |
| Proteinuria | < 300 mg/24 hr | mg | >= 300 = significant (preeclampsia) |
| AST / ALT | 10 -- 40 | U/L | Elevated in HELLP, preeclampsia |
| Uric Acid | 2.5 -- 6.0 | mg/dL | Elevated in preeclampsia |
| Fasting Glucose (pregnancy) | < 92 | mg/dL | GDM: fasting >= 92, 1hr >= 180, 2hr >= 153 |
| Fetal Fibronectin | Negative | -- | Negative predictive value for preterm delivery < 7 days |
| AFP (maternal serum) | MoM 0.5 -- 2.0 | MoM | Elevated: neural tube defect; Low: Down syndrome |
| Amniotic Fluid Index | 5 -- 25 | cm | < 5 = oligohydramnios; > 25 = polyhydramnios |
| FSH (menopausal) | > 25 (post-menopausal) | mIU/L | Confirm menopausal status |
| Estradiol (follicular) | 20 -- 150 | pg/mL | Low in premature ovarian insufficiency |
| AMH | Age-dependent (1.0 -- 4.0 reproductive age) | ng/mL | Ovarian reserve marker |

## Red-Flag Symptoms

- **Vaginal bleeding with pain in early pregnancy** -- ectopic pregnancy until proven (quantitative hCG + transvaginal US; hemodynamic instability = surgical emergency)
- **Heavy vaginal bleeding after 20 weeks** -- placenta previa (do NOT perform digital cervical exam; ultrasound first)
- **Severe abdominal pain + rigid uterus + fetal distress** -- placental abruption (emergent delivery)
- **Severe headache + visual changes + epigastric pain + BP >= 160/110** -- severe preeclampsia (IV magnesium seizure prophylaxis, plan delivery)
- **Seizure in preeclamptic patient** -- eclampsia (IV magnesium, stabilize, deliver)
- **Preterm labor** (regular contractions + cervical change < 37 weeks) -- tocolytics, betamethasone for fetal lung maturity, GBS prophylaxis
- **Decreased fetal movements** -- kick count assessment, NST (non-stress test), BPP (biophysical profile)
- **Postpartum hemorrhage** (> 500 mL vaginal, > 1000 mL cesarean) -- massage fundus, oxytocin, misoprostol, tranexamic acid; consider Bakri balloon or hysterectomy
- **Fever + uterine tenderness + foul lochia postpartum** -- endometritis (antibiotics)
- **Sudden onset dyspnea + chest pain postpartum or post-cesarean** -- pulmonary embolism or amniotic fluid embolism (CTPA if stable)
