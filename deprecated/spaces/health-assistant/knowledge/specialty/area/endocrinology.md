# Endocrinology

## Key Terms and Abbreviations

| Term | Abbreviation | Meaning |
|------|-------------|---------|
| Type 1 Diabetes Mellitus | T1DM | Autoimmune beta-cell destruction |
| Type 2 Diabetes Mellitus | T2DM | Insulin resistance with relative deficiency |
| Diabetes Insipidus | DI | ADH deficiency or resistance |
| Syndrome of Inappropriate ADH | SIADH | Excess ADH secretion |
| Thyroid Stimulating Hormone | TSH | Pituitary thyroid axis marker |
| Free Thyroxine | FT4 | Active thyroid hormone |
| Hemoglobin A1c | HbA1c | 3-month glycemic average |
| Diabetic Ketoacidosis | DKA | Life-threatening T1DM complication |
| Hyperosmolar Hyperglycemic State | HHS | Life-threatening T2DM complication |
| Cushing Syndrome | -- | Cortisol excess |
| Addison Disease | -- | Primary adrenal insufficiency |
| Estimated Glomerular Filtration Rate | eGFR | Kidney function for dosing |
| Continuous Glucose Monitor | CGM | Real-time interstitial glucose |
| Multiple Endocrine Neoplasia | MEN | Familial endocrine tumor syndrome |

## Common Tests and Procedures

- **HbA1c** -- glycemic control (every 3 months if not at goal)
- **Fasting Glucose / Oral Glucose Tolerance Test (OGTT)** -- diabetes screening
- **TSH with reflex FT4** -- thyroid disorder screening
- **Thyroid Antibodies (TPO, TgAb)** -- autoimmune thyroiditis (Hashimoto)
- **Thyroid Uptake Scan** -- hyperthyroidism etiology (Graves vs. thyroiditis vs. nodule)
- **Cortisol (8 AM) + ACTH** -- adrenal insufficiency screening
- **Dexamethasone Suppression Test (overnight/24h)** -- Cushing screening
- **PTH + Calcium** -- hyperparathyroidism evaluation
- **25-OH Vitamin D** -- vitamin D deficiency screening
- **Insulin / C-peptide** -- endogenous insulin production assessment
- **Bone Density (DEXA)** -- osteoporosis screening

## Red-Flag Symptoms

- **Kussmaul breathing + fruity breath + altered mental status** -- DKA (check glucose, ketones, ABG)
- **Glucose > 600 mg/dL + altered sensorium + no ketosis** -- HHS
- **Thyroid storm** -- fever > 102, tachycardia, delirium, atrial fibrillation
- **Myxedema coma** -- hypothermia, altered mental status, hypotension, hyponatremia
- **Acute adrenal crisis** -- hypotension refractory to fluids, hyperkalemia, hyponatremia, hyperpigmentation
- **New-onset severe hypercalcemia** (> 14 mg/dL) -- IV hydration + calcitonin + bisphosphonate
- **Postpartum headache + visual field defect** -- pituitary apoplexy / Sheehan syndrome
- **Rapidly expanding neck mass + stridor** -- compressive goiter or thyroid cancer
- **Hypoglycemia unawareness** -- loss of autonomic warning signs in T1DM
- **New-onset diabetes in a thin young person with weight loss** -- suspect T1DM, check C-peptide and antibodies
