# Phase 1 — Plan & Gather

Run four tasklist nodes in order: **plan → search → triage → read**.

```ts
// Declare the tasklist ONCE (the harness block above shows the literal DAG).
const __flow = tasklist("deep_research", { /* DAG from harness */ });

// ── plan ────────────────────────────────────────────────────────────────
__flow.start("plan");
const plan = {
  mode: "broad" as const,          // or "deep" | "news" | "academic"
  subqueries: [/* 1–3 sharpened query strings — decompose multi-hop */],
  freshness: "all" as const,
  topic: "general" as const,
};
__flow.finish("plan", plan);

// ── search ──────────────────────────────────────────────────────────────
__flow.start("search");
const rawResults: any[] = [];
const searchErrors: string[] = [];
for (const q of plan.subqueries) {
  try {
    const hits = await webSearch(q, { topK: 8, freshness: plan.freshness, topic: plan.topic });
    rawResults.push(...(hits as any[]));
  } catch (e) {
    searchErrors.push(String(e));
  }
}
// If ALL searches returned nothing, note it so downstream steps can report honestly.
if (rawResults.length === 0) {
  searchErrors.push("All searches returned 0 results. Check provider configuration or try different queries.");
}
__flow.finish("search", { rawResults });

// ── triage ──────────────────────────────────────────────────────────────
__flow.start("triage");
// Canonicalize URLs (strip utm_*, fragments, trailing /). Dedupe. Rank by
// (score + authorityBoost). Drop SEO-spammy domains. Keep top 5.
const topUrls: string[] = /* string[] of up to 5 URLs */ [];
__flow.finish("triage", { topUrls });

// ── read ────────────────────────────────────────────────────────────────
__flow.start("read");
const excerpts: Array<{ sourceId: string; title: string; url: string; text: string | null; error?: string }> = [];
for (let i = 0; i < topUrls.length; i++) {
  const url = topUrls[i]!;
  const sourceId = `source-${i + 1}`;
  try {
    const doc = await readDocument(url, { byteBudget: 30000, pages: url.endsWith(".pdf") ? "1-5" : undefined });
    excerpts.push({ sourceId, title: url, url, text: doc.text });
  } catch (e) {
    excerpts.push({ sourceId, title: url, url, text: null, error: String(e) });
  }
}
__flow.finish("read", { excerpts });

// ── yield ───────────────────────────────────────────────────────────────
// Pass searchErrors so cycle 2 knows if searches failed or returned nothing.
await inspect(plan, topUrls, excerpts, searchErrors);
```

End the cycle here. The truncated `__excerpts`, `__topUrls`, and `__plan` will be visible in cycle 2's reconstruction.

## Notes

- `webSearch` already filters out unconfigured providers; do NOT pass `providers` explicitly.
- For specialized deep extraction on a single complex URL, you may `delegate({ agent: "reader", task: "extract the key data from <url>" })` instead of calling `readDocument` directly.
- If the cumulative excerpt text is much larger than the next cycle can hold, drop the lowest-ranked sources before yielding.
