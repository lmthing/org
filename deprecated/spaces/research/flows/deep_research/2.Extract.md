# Phase 2 — Extract claims

From the resurfaced `__excerpts` (visible in this cycle's reconstruction), extract a structured list of supported claims.

```ts
__flow.start("extract");

// If searches returned nothing, propagate that signal as a single sentinel
// claim so the synthesizer knows to report "no results" rather than fabricate.
const hasExcerpts = Array.isArray(__excerpts) && __excerpts.some((e: any) => e.text);
const hadSearchErrors = Array.isArray(__searchErrors) && __searchErrors.length > 0;

const claims: Array<{
  claim: string;          // 1-sentence factual statement
  sourceId: string;       // e.g. "source-2"
  evidence: string;       // short quoted/paraphrased phrase from the excerpt
}> = hasExcerpts
  ? [
      // Walk every excerpt with text !== null. For each, identify atomic factual
      // claims that are useful to the user's task. Bind each to its source.
      // If an excerpt was truncated, re-query inspect([__excerpts[i], { path: "text", slice: [0, K] }])
      // BEFORE this cycle finishes — only what you read here can be cited later.
    ]
  : []; // empty: no readable excerpts

__flow.finish("extract", { claims });

await inspect(claims);
```

## Rules

- Every claim must cite **one** source. If multiple sources agree, emit one claim per source.
- Disagreements: surface them as separate claims, do NOT smooth into a consensus claim.
- Evidence string ≤ ~200 chars. Long enough to be load-bearing, short enough to fit.
- If `__excerpts` previews show some text was truncated and that text matters, re-query first.
